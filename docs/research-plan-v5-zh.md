# v5 突破方案：用 Jev 做不到的事赢 Jev（2026-11-12 晚）

> 写给：llav 项目负责人。前提：4B 逐条重排器已到 Jev 的 90–100%，再调只能"小赢小输"。本文只做三件事：(1) 用今晚从 trace 里算出的数据把端到端差距**归因到具体环节**；(2) 列出结构上不同于 pointwise judge 的做法并逐一估值；(3) 给出前三个赌注、各 3–5 天的实验计划、今晚该启动什么。不含代码。分析脚本（纯 CPU，读 trace / dump）已存到 `~/models/evals/sag2/analysis-v5/`：`loop_attr.py`（逐轮池召回与丢失归因）、`ev_pull.py`（回放 dump 上的证据拉扯）、`e2e_pull.py`（端到端 trace 上的证据拉扯 + 跳数分布）、`never.py`（从未检到金标的位置与可达性）。

## 执行摘要（约 300 字）

**差距在哪**：q0–50 同题对比 Jev（0.933）与我们（0.780）的端到端 trace：第 0 轮前十召回相同（0.700 vs 0.698），两轮扩展后候选池召回几乎相同（0.963 vs 0.952，"从未检到"的金标 5 vs 7），**全部差距 = 最后一轮的排序：金标在池里却排在前十之外，Jev 4 个、我们 23 个（共 132 个金标）**。机理是**证据锁死（evidence lock-in）**：上一轮前十被当作 `previously_retrieved_evidence` 喂回来，我们的模型给"在证据里的非金标"平均 0.83 分（Jev 0.08），于是前十被自我确认、冻结，新找到的金标中位名次 19，进不了前十（新金标进前十 31% vs Jev 60%）。回放实验用的是 Jev 的干净证据，所以只量到这个问题的三分之一（−0.03），真实循环里它放大到 −0.14。

**Jev 自己的天花板**：在更难的 q50–350，Jev R@10 0.85–0.87，其中 **9.5% 的金标从未被词面扩展检到**（75/789，多数是最后一跳的答案段落），这是判别器无论多好都碰不到的损失；4 跳题 Jev 只有 0.70–0.72。

**三个赌注（按胜率排序）**：
1. **集合级终轮判别**（top-30 一次前向、候选互相可见、输出一致的证据链）——直接消灭锁死，并利用 pointwise 合约做不到的"链一致性"。今晚启动。
2. **生成式下一跳查询（llav-loop）**——用本地大模型/自训头从种子段落推断桥接实体写下一跳查询，攻 Jev 碰不到的 9.5% 检索上限；系统级对比。
3. **9B/27B 骨干 + Jev 分布蒸馏 + 金标纠正 + 证据一致性正则**——第 0–1 轮与级联底座、校准与 API。

**目标**：不改 SAG2 循环：MuSiQue 1,000 题 R@10 ≥ 0.90（Jev 0.866）、4 跳 ≥ 0.82（Jev ≈0.71），2Wiki/HotpotQA 不低于 Jev −0.01；llav-loop：MuSiQue ≥ 0.93。"决定性" = 在 ≥300 题上配对 bootstrap 显著且 ≥ +4 分。

## 1. 差距的第一性原理归因（数据来自 trace，CPU 可复现）

SAG2 的每一轮都是 `score = f(question, evidence, candidate)`；最终前十只取**最后一轮**的分数（`retained` 每轮覆盖），前两轮分数只决定：种子（前十 → 扩展词，权重 0.5+0.5·s/max）、证据（第 1 轮 = 10 种子 + 前 10 个未判新候选；第 2 轮 = 上轮前十）、第 2 轮的历史截断（~105 旧 + 20 新）。所以端到端 R@10 = 候选池召回 × 终轮池内前十召回。

| q0–50，132 个金标 | Jev 1.14 | llav ckpt2750（v1 格式） |
|---|---|---|
| 第 0 轮前十召回（全金标口径） | 0.700 | 0.698 |
| 第 1 轮 池召回 / 前十召回 | 0.918 / 0.898 | 0.900 / **0.768** |
| 第 2 轮 池召回 / 前十召回（= 端到端） | 0.963 / 0.933 | 0.952 / **0.780** |
| 丢失金标：从未检到 / 被历史截断 / 在池内但 >10 | 5 / 1 / 4 | 7 / 0 / **23** |
| 第 2 轮：证据里的非金标 平均分 / 留在前十 | 0.084 / 0.594 | **0.834** / 0.673 |
| 第 2 轮：新金标（不在证据里）进前十 | 0.600（n=10） | **0.308**（n=26） |
| 第 0 轮种子分数曲线 rank1→10 | 0.45→0.07 | 0.96→0.40（秩归一化+集成） |
| 两者第 0 轮种子重合 4.6/10，扩展词重合 0.61，新候选重合 0.58 | | |

归因（R@10 口径）：
- **第 0 轮判别：0**。我们在第 0 轮已持平/略优（q0–50 单模型 0.942）。
- **检索循环（种子→扩展词→新候选）：≈ −0.015**。尽管种子权重曲线因秩归一化而变平、扩展词只重合 61%，池召回只差 0.011。
- **终轮排序（自己的证据、自己的候选池）：≈ −0.14**。其中回放可量到的"纯判别差"≈ −0.035（soupC hop2 池内 0.928 vs 0.960），其余 ≈ −0.10 是锁死动力学：证据非金标被打成 0.83 → 前十冻结 → 新金标卡在 19 名。v4 把证据非金标压到 0.25，但新金标召回反而掉到 0.5——它学会了"证据里的不一定对"，却没学会"证据之外的也可能对"，净效果为零（§AE）。
- **选择策略 / DPP：R@10 为 0**；但秩归一化把前十分数压成 0.9–1.0，DPP 核退化成纯多样性，解释 R@2 0.465 vs 0.69 的一部分。

**Jev 自己的上限**（q50–350，789 金标）：从未检到 75（9.5%）、池内 >10 名 54。75 个里 41 个是最后一跳段落，只有 21 个的标题逐字出现在已检到的金标里——即词面扩展原则上只能再救三成，其余要靠**推断**桥接实体。按跳数：Jev 2 跳 0.92–0.94，3 跳 0.80–0.85，4 跳 0.70–0.72（1,000 题里 518/316/166）。

**单变量实验（每个 ≤ 半天，先于一切训练）**：
- E1 锁死确认：(a) 今晚队列里的 soupC 级联端到端——若终轮池内召回仍 ≈0.82 而回放是 0.928，锁死成立；(b) 第 1–2 轮**屏蔽证据**（服务端用第 0 轮模型、不传 evidence）跑 50 题：若端到端反而上升，证明现在的证据条件化是净负；(c) 服务端输出 Platt 校准概率而非秩归一化（只改种子权重与 DPP）。
- E2 环节交换（花 $0.1）：第 0–1 轮用 Jev 分、第 2 轮用我们；再反过来。直接拆"循环"与"终轮"。
- E3 骨干单变量：同一 v5 数据训 4B 与 9B，只比回放 hop1/2。
- E4 检索上限：对 q50–350 的 75 个"从未检到"，用生成式查询离线 BM25（`.cache/sag2/musique.sqlite` 可 CPU 查）看能捞回多少——这是赌注 2 的 go/no-go。

| **I 变换一致性正则（新增）** | 训练时同一候选配两套证据（含/不含自己、换掉非金标）分数差受罚，即 JevBench 的 metamorphic 定律 | 直接训练出 Jev 的"批次独立/证据鲁棒"，而不是靠数据碰 | 锁死的根治项 | 数据翻倍，零新代码量 | 过强会失去证据条件化的好处 | 同 F |

结论：A 是唯一同时"治病"（锁死）和"超越"（链一致性）的；B 是唯一能越过 Jev 自身上限的；E+F+I 是底座。C、G、H 并入 A/B。

## 3. 前三赌注与计划

### 赌注 1：集合级终轮判别 llav-set（今晚启动）
- **数据（CPU，今晚）**：(i) v5 trace 的 2,700 轮（三数据集）每轮一个集合：Jev 前 30 ∪ 池内全部金标；(ii) 半 on-policy：同池用 soupC 前 30（明早 GPU 空时 4 h 打分）；(iii) 原生集合数据：MuSiQue 训练集 2 万题 × 20 段（2–4 金标）、HotpotQA/2Wiki distractor 各 1 万题 × 10 段——天然就是"集合→哪些是证据"。打乱顺序增强，集合大小 10–30 随机。
- **模型**：Qwen3-Reranker-4B + LoRA（从 soupC 热启动），序列 = 问题 + `[1] 标题: 段落 … [30]`，每个候选末尾标记位读 yes/no logit；损失 = 集合内 listwise CE + 逐标记 BCE。第二天换 Qwen3.5-9B-Base / Prism-9B 做 E3。
- **服务**：第 2 轮（state 含 `previous_jev_score`）→ 0.6B 预筛 120→30 → 集合模型一次前向；30 之外沿用预筛分（llav-serve3 已有该模式）。第 0–1 轮仍用 soupC 集成。
- **评测协议**：D1–2 回放 Jev hop-2 池 q0–50（目标池内 R@10 ≥0.96）→ q50–200 选存档；D3 端到端 q0–50（目标 ≥0.90）；D4 q50–200（目标 ≥0.88，Jev 0.85）；D5 q200–350 终测 + 2Wiki/HotpotQA 各 50。
- **零样本 v0（明早 GPU 空档 1 h）**：Arete-27B-8bit 或 Flash-Next 对 hop-2 dump 的 top-30 做"写链→置顶"（做法 H），立即得到集合级上界信号；若 v0 已 ≥0.95，训练目标就是把它蒸进 4B/9B。

### 赌注 2：生成式下一跳查询 llav-loop
- **D1 可行性（CPU + Splash）**：q50–350 的 Jev trace：问题 + 第 0 轮前十种子 → Flash-Next JSON 出 3 条下一跳查询 → `CorpusIndex.retrieve` 各取 50 → 75 个"从未检到"金标捞回 ≥40% 且池只增 ≤60 个即 go。
- **D2 集成**：fork `sag2.py` 加 `--query-writer`，生成候选占扩展交错槽位；judge 用 soupC 集成；端到端 q0–50、q50–200。
- **D3–4 自训查询头**：Qwen3.5-4B-Base（或 9B）SFT：输入问题 + 种子段落，输出已解析桥接实体的下一跳子问题（MuSiQue 分解 2 万条；Hotpot/2Wiki 用金标标题构造）；替掉 84 GB 的 Flash-Next。
- **D5**：4 跳题加第 3 轮，停止条件 = 赌注 1 模型的"链完整"信号。
- **目标**：MuSiQue 1,000 题 R@10 ≥0.93，4 跳 ≥0.85；报告时与"SAG2 原循环 + llav"并列。

### 赌注 3：9B/27B pointwise 底座 + 蒸馏纠正 + 一致性
- **数据**：v5 11.3 万行 + 半 on-policy 证据变体 + 一致性配对（含/不含自己、换非金标）。
- **目标函数**：金标 CE + listwise + 0.5·BCE(Jev 分)（Jev ≥0.7 且金标为假、或 ≤0.1 且为真的行屏蔽）+ 一致性惩罚。
- **模型**：D1 用已有 v5 脚本在 4B 上加 `--soft 0.5` 作对照；D2–3 Prism-Qwen3.5-RR-9B（MIT，需下载 ~18 GB）LoRA，group 4、2048 ctx；D4 评回放/校准/端到端；D5 若 9B 收益 ≥ +0.01，27B 8-bit QLoRA（下载 Qwen3.8-27B 基座 MLX 8-bit，Arete 是 SFT 版不宜）跑一夜。
- **目标**：回放 hop2 池内 R@10 ≥0.95、证据非金标均分 ≤0.2、Brier ≤0.013；端到端 q0–50 ≥0.90（原循环）。

**今晚 GPU 单占序列**：final350-soup → 级联端到端（=E1a，保留）→ 把队列里的 v5 pointwise 训练换成赌注 1 的集合级训练（数据今晚 CPU 建好）；v5 pointwise 改到明晚在 9B 上跑（赌注 3）。零样本 27B 集合测试放在明早训练间隙。

## 5. 诚实的风险与"决定性"的定义
- **Jev 可能不可逾越的部分**：循环级鲁棒性（证据非金标 0.08、顺序不敏感、Brier 0.011）来自海量 LLM 共识标注；我们 11.3 万行 + 公开 QA 集只能在**有金标的任务**上赢它，通用 typed decision 仍要 27B + jev-distill-corpus，是另一条线。
- **天花板效应**：2Wiki 0.975 / HotpotQA 1.000 只能持平；MuSiQue q0–50 一题 = 2 分，50 题上 ±0.03 是噪声，任何"决定性"都只能在 ≥300 题上配对 bootstrap 说；原循环下 q50–350 的池召回上限 0.91–0.92，Jev 已 0.85–0.87，**不改循环最多赢 5–6 分**，改循环（赌注 2）才可能赢 10 分。
- **协议张力**：集合级判别违反 Jev 的 batch-independence 合约；在 SAG2 里整池同在一个 state 没问题，API 要同时提供 pointwise 模式。
- **更硬的考场（开放地带）**：MuSiQue 3/4 跳子集（316/166 题，Jev 0.80/0.71）；MuSiQue 全 1,000 题（Jev 参考用论文 0.866，预算已尽）；加第 3 轮的 4 跳评测；FRAMES（824 题 2–15 跳，维基）与 EnterpriseRAG 作为"更长视野"的泛化考；以及"金标与 LLM 共识不一致"子集——那是 llav 论点（学真实结果而非 LLM 意见）最直接的证据。
